# Construction Code System — Setup Instructions for Agent

## 1. Goal

Implement a **6-digit cost code system** for a construction workflow app.

The codes are used for:

- Scopes of work
- Estimates / quotes
- Job costing
- Scheduling & trade tracking
- Linking (later) to building code rules by department

> ⚠️ Building code (MA 780 CMR, 248 CMR, NEC, etc.) is **NOT** part of this file.  
> That will be a **separate mapping**, triggered by `dept_code` or other fields.

---

## 2. Code Format

Each code is **6 digits** using this pattern:

`DDD L TT`

Where:

- `DDD` = 3-digit **Department / Trade code**
- `L`   = 1-digit **Cost Type**
- `TT`  = 2-digit **Subcategory** within that department

Example:

- `720102` = Dept **720 (Flooring)**, **Labor** (1), Subcategory **02 (Tile flooring)**

## 5. Codes Table (Flattened)

Create a **`codes`** table/collection that contains **all valid 6-digit codes**.

Recommended fields:

- `id` (primary key, optional)
- `full_code` (string, 6 digits, e.g. "720102")
- `dept_code` (int, e.g. 720)
- `cost_type_code` (int, 0–5)
- `sub_code` (string, 2 digits, e.g. "02")

Lookups (optional but useful):

- `dept_name` (denormalized for speed)
- `cost_type_label`
- `sub_label`

### 5.1 How to generate `full_code`

For each combination:

- Take `dept_code` (3 digits). If integer, left-pad: `100`, `600`, `720`, etc.
- Take `cost_type_code` (single digit 0–5)
- Take `sub_code` (2 digits, already "01", "02", etc.)
